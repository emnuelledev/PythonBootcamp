# 🐍 100 Days of Python

This repository documents my progress through **100 Days of Code™: The Complete Python Pro Bootcamp**, by Dr. Angela Yu.

## About

Although I already have experience using Python in software development, automation, testing, API integrations, and data processing, I decided to revisit the language systematically from the fundamentals.

The goal is to strengthen my Python foundation, reinforce core programming concepts, and progressively work through more advanced topics and projects.

Rather than skipping familiar material, I'm using the course as an opportunity to revisit concepts in depth, improve my problem-solving skills, and build greater fluency with Python.

## 🎯 Objectives

* Reinforce Python fundamentals and core programming concepts
* Strengthen algorithmic thinking and problem-solving
* Improve Python fluency and code quality
* Revisit data structures, functions, OOP, and error handling
* Practice debugging and code organization
* Build progressively more complex Python projects
* Maintain consistent hands-on programming practice

## 📚 Topics

Throughout the challenge, I'll work with topics including:

* Python fundamentals
* Control flow
* Functions and scope
* Data structures
* Object-Oriented Programming
* Error handling
* File handling
* APIs
* Automation
* Web scraping
* Databases and SQL
* Flask
* Pandas and NumPy
* Data analysis
* Git and version control

## 🚀 Purpose

For me, this challenge is less about simply completing 100 days and more about **strengthening the foundations that more advanced software engineering is built on**.

Revisiting the fundamentals helps me identify gaps, reinforce concepts I already use professionally, and develop a deeper and more systematic understanding of Python.

The repository serves as a record of that continuous learning process.
